## What ships

A "Download all my designs" link on `/designs` (My Designs). It downloads one
zip holding every image the signed-in viewer owns, stored uncompressed, plus a
`manifest.json`. The zip is streamed by a GET route handler at
`/designs/export` (outside `/api`, owner-approved exception). Guests from the
guest funnel may export (they own their images); a visitor with no session
gets a 401.

## Design

- **Rows.** `getUserImageLibrary` (the My Designs source) selects `image`
  where `owner_id = userId`, newest first, but joins `listing` and reads
  `product` for backdrops and has none of operation / prompt / aspect ratio.
  The export runs its own query in `design-export.ts` with the same filter and
  order over `image` alone. A real-DB test pins that the two return the same
  id set, so the two cannot silently drift.
- **Objects.** Key = `image.r2_key`, else `imageKeyFromUrl(image.image_url)`
  (legacy rows live at `designs/{designId}/{n}.png`, which `getImageObject`,
  being `images/{id}.png`-only, would miss). New `getObjectByKey(key)` in
  `r2.ts` returns the bytes or null on any failure, like `getImageObject`.
- **Zip.** `fflate` streaming `Zip` + `ZipPassThrough` (stored, method 0).
  A pull-based `ReadableStream`: each `pull` reads one object, pushes it
  through the zip, enqueues the produced chunks, and returns. At most one
  image buffered at a time. `manifest.json` is the last entry.
- **Filenames.** `<YYYY-MM-DD>_<imageId>.png`, date = the image's created
  calendar day in `America/Los_Angeles` (house rule: a human-facing calendar
  day is Pacific), id sanitized to `[A-Za-z0-9_-]`; uniqueness is enforced
  explicitly (a `-2`, `-3` suffix if two sanitized names ever collide).
- **Manifest.** `{ exportedAt, timestampTimeZone: "UTC",
  filenameDateTimeZone: "America/Los_Angeles", imageCount, includedCount,
  missingCount, images: [{ imageId, filename, included, operation, prompt,
  aspectRatio, createdAt }] }`. `createdAt`/`exportedAt` are ISO 8601 UTC
  (`toISOString()`, ends in `Z`). A missing entry has `included: false` and
  `filename: null`. Order = the rows' order (newest first).
- **Missing objects.** No key, a null read, or a throwing read → skipped,
  listed with `included: false`. Never fatal.
- **Route.** `src/app/designs/export/route.ts`, `GET(request)`:
  `auth.api.getSession({ headers: request.headers })`; no session → 401;
  `canUseStudio(user, guestFunnelEnabled())` false → 403 (the `/designs` page
  gate's predicate, `requireStudioUser`). The proxy matcher covers `/designs`
  exactly, not sub-paths, so the handler is the only gate. 200 response:
  `Content-Type: application/zip`, `Content-Disposition: attachment;
  filename="prntd-designs-<Pacific YYYY-MM-DD>.zip"`, `Cache-Control:
  no-store`, `X-Content-Type-Options: nosniff`, no `Content-Length`.
  `export const dynamic = "force-dynamic"`, `export const maxDuration = 300`.
- **Link.** A client component on `/designs`, shown only when the library is
  non-empty: a plain `<a href="/designs/export" download>` (not `next/link`:
  no prefetch, no client routing; a phone browser treats the attachment as a
  normal download). Label "Download all my designs". On tap it switches to
  "Preparing download…", `aria-disabled`, ignores further taps for a few
  seconds, then resets. Paper look, secondary-button styling, no rose.

## Tasks

### Task 1 — `design-export.ts`, `getObjectByKey`, `fflate`

Add `fflate`. Add `getObjectByKey` to `r2.ts`. Write `src/lib/design-export.ts`:
`loadExportRows(db, userId)`, `exportObjectKey(row, keyFromUrl)`,
`assignExportFilenames(rows)`, `buildExportManifest(...)`,
`exportArchiveName(now)`, `createDesignExportStream({ rows, readObject, now })`.

Acceptance:
1. `loadExportRows` reads `image` only, filtered by owner, newest first with
   the rowid tiebreak.
2. Filenames are unique and encode the Pacific created date and image id.
3. The stream is a valid zip: `unzip -tq` exits 0 on it, every entry uses
   compression method 0, and the entries equal the manifest's included
   filenames plus `manifest.json`, byte-identical to the source objects.
4. A null or throwing read is skipped and listed as missing; the zip is still
   valid.
5. `readObject` is never called for image n+1 before image n's bytes were
   enqueued (at most one in flight).
6. Manifest timestamps are UTC ISO 8601 ending in `Z`.

Tests (`src/lib/__tests__/design-export.test.ts`, node env;
`src/lib/__tests__/design-export.integration.test.ts`, real DB):
- filename date across the UTC-midnight / Pacific-evening boundary;
  uniqueness including two ids that sanitize to the same string;
- manifest shape, UTC `Z` timestamps, zone fields;
- stream → bytes → `unzip -tq` (temp file) and `fflate.unzipSync` read-back
  matching the manifest; method-0 check from the central directory;
- missing (null) and throwing reads → `included: false`, zip still valid;
- one-at-a-time: a reader that tracks in-flight calls never exceeds 1, and a
  consumer that reads only the first chunk triggers at most one read;
- empty rows → a valid zip holding only `manifest.json`;
- real DB: `loadExportRows` returns the caller's images and not another
  user's; same id set and order as `getUserImageLibrary`; legacy row with
  `r2_key` null resolves its key from `image_url`;
- guard: `design-export.ts` does not import `listing`, `product` or `order`
  from the schema.

### Task 2 — route handler and the link on `/designs`

Acceptance:
1. No session → 401, and neither the DB nor R2 is read.
2. A guest session with the guest funnel on → 200 zip of the guest's images
   only; with the funnel off → 403.
3. A signed-in user → 200 zip of their images only; another user's images
   are absent.
4. A missing R2 object is listed as missing; response is still 200 and a
   valid zip.
5. Headers as in Design.
6. `/designs` shows the link when there is at least one image, not in the
   empty state; the link is `href="/designs/export"` with `download`; a tap
   shows "Preparing download…" and a second tap in that window does nothing.

Tests: `src/app/designs/__tests__/export-route.integration.test.ts`
(`// @vitest-environment node`, real DB, `@/lib/auth` and `@/lib/r2` mocked,
zip read back); `src/app/designs/__tests__/page.test.tsx` extended;
a component test for the link.
