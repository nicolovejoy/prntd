# #278 slice 6a: remove the old `/preview` checkout code

Date: 2026-10-15. Branch `claude/278-slice-6a`, worktree `.claude/worktrees/278-slice-6a`. One PR. No schema change; if one appears, stop and report.

## What this slice does

`/preview` has been a server redirect to the image detail page since slice 4 (#294, 2026-10-06), and the cart went to embedded checkout in #314 (2026-10-11). The code that served the old `/preview` buy page is dead unless a client calls a server action by hand. This slice removes it:

1. `createCheckoutSession` and `calculatePrice` in `src/app/order/actions.ts`, and the file itself if nothing else is left. The one comment in `src/app/cart/actions.ts` (#333) that says `createCheckoutSession` is not counted by the checkout quota goes with it.
2. `PREVIEW_EMBEDDED_CHECKOUT_ENABLED`: `previewEmbeddedCheckoutFlag` in `src/lib/flags.ts`, `previewEmbeddedCheckoutConfig` and the two-switch `embeddedCheckoutPageConfig` / `embeddedCheckoutPageFlag` in `src/lib/embedded-checkout.ts` and `src/lib/flags.ts`. `/checkout` (`src/app/checkout/page.tsx`) 404s unless `EMBEDDED_CHECKOUT_ENABLED` alone is on; its docblock says so.
3. The cart's legacy `designId` entry in `addToCart` (`src/app/cart/actions.ts`): the `designId` branch of `resolveLineInput` and its parameter. After this, `frontImageId` is required. Trace every caller first (`grep -rn "designId" src/app/cart src/app/d src/app/preview src/app/design src/app/studio`); the image detail page's panel and the cart's Save path must keep working unchanged.
4. `src/app/preview/actions.ts`: `getLastPurchaseDefaults` stays only if something outside `/preview` imports it; otherwise move or delete it (check `src/lib/purchase-defaults.ts` and the image detail page's panel first).
5. `scripts/`, `docs/stripe-e2e.md`, `e2e/**`, `.github/workflows/*.yml`, `ci.yml`'s env blocks and `.env.tpl`: remove `PREVIEW_EMBEDDED_CHECKOUT_ENABLED` wherever it still appears. Do not edit `CLAUDE.md`; the controller does that.

The `/preview` and `/order` redirects stay. `src/app/preview/page.tsx` (the redirect) stays. `getLastPurchaseDefaults`'s behaviour on the image detail page stays.
