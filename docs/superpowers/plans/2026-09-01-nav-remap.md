# Nav re-map: the Studio enters navigation

Decided by Nico 2026-09-01 ("Option A"): re-map the existing header now;
the fuller bottom-tab redesign waits until studio slices 4+5 have landed
and been lived with. Three sub-decisions, all his: "New Design" leaves the
nav (the Studio composer replaces it), the signed-in landing becomes the
Studio, ship now rather than folding into slice 4/5.

## Spec

### 1. `src/components/site-header.tsx`

- Signed-in top-level links, in order: **Studio** (`/studio`),
  **My Designs** (`/designs`), **Shop** (`/prints`), **Orders** (`/orders`),
  then the existing conditionals last: Dashboard (`storesEnabled`) and
  Admin (`isAdmin`). One `links` array as today — desktop renders it inline,
  the mobile dropdown renders the same list, so "moved later" is the whole
  change for the role-specific entries.
- **"New Design" is deleted.** Two doors into the same territory is the
  incoherence this fixes: an unanchored Generate in the Studio composer IS
  new design.
- The running-jobs badge (`data-testid="running-jobs-badge"`) links to
  **`/studio`** instead of `/designs` — the Studio is where running
  generations render as pending cells, so it is now the one right answer
  for "where is my generation". Update its comment.
- Signed-out nav unchanged: Shop + Sign in.

### 2. `src/app/page.tsx`

- A signed-in, non-anonymous visitor to `/` is redirected server-side to
  `/studio` (`auth.api.getSession` + `isAnonymousUser` from `@/lib/auth`,
  `redirect` from `next/navigation`), before the feed/promo fetches.
- Anonymous guests and cookie-less visitors keep the MakerHero landing
  unchanged — an anon guest redirected to /studio would bounce off
  `requireRealUser` into /sign-in, which is a worse landing than the
  composer.
- This deliberately reverses #82's "no session read on the homepage": the
  divergence #82 killed was two different *homepages*; this is a redirect
  to a different surface entirely (plan slice 5's landing recommendation,
  pulled forward). Say so in a comment. The page is already
  `force-dynamic`, so no rendering-mode change.

### 3. Tests

- New `src/components/__tests__/site-header.test.tsx`: signed-in link set
  is exactly Studio/My Designs/Shop/Orders in order with New Design absent;
  Dashboard/Admin appear only with their flags; signed-out shows Shop +
  Sign in; the running-jobs badge hrefs to `/studio`. Mock
  `@/lib/auth-client` (`useSession`), `@/components/site-header-actions`
  (`getHeaderState`), and the feedback launcher.
- Home redirect coverage: signed-in real user → redirect("/studio");
  anonymous guest → renders the hero (no redirect). Mock `@/lib/auth` +
  `next/navigation`.

### 4. Docs

- `docs/studio-plan.md` slice 5: note that the nav half (Studio in nav,
  New Design removed, landing = Studio) shipped 2026-09-01 ahead of the
  slice; slice 5 retains My-Designs-becomes-image-grid and the image
  detail "Open conversation" action.

### Out of scope

- Any bottom tab bar or header restructure (Option B — revisit after
  slices 4+5).
- `/design` itself: still reachable from Studio lanes and My Designs
  cards; only its nav entry goes.

### Gates

`npm run lint`, `npm run typecheck`, `npm test`, `npm run build`.
